# Ballot-proposition ground truth (updates/03_experiments.md Task 2.2)

This arm needs something the rest of the project does not have: **a real human
baseline with a known answer.** A model's questionnaire score is compared to a
centre-point; a model's vote on a real ballot measure can be compared to how
people actually voted.

That data is not shipped in this repository, and it is not generated by any
script here, because ballot-measure results are factual records. Inventing
plausible-looking vote shares would corrupt the one arm whose value is that its
numbers are true. Download them from a primary source instead.

## Where to get it

| Source | What it gives | Notes |
|---|---|---|
| Official Secretary of State results pages, per state | Certified vote totals | Authoritative; slow to assemble |
| Ballotpedia's ballot-measure database | Measure text, subject tags, results | Check reuse terms before redistributing |
| MIT Election Data and Science Lab (Harvard Dataverse) | Tidy state-level returns | Best starting point for bulk download |
| State party platforms / endorsement records | Partisan endorsement per measure | Needed for the endorsement comparison |

Target set per updates/03_experiments.md: **~200 US state ballot measures, 2016-2024**, with
published results and a partisan endorsement record. 100 are enough to run the
arm; the plan budgets 100 propositions x 19 models x 5 trials = 9,500 calls.

## Schema

Write `data/ballot/propositions.csv` with exactly these columns:

| Column | Type | Meaning |
|---|---|---|
| `id` | string | Stable identifier, e.g. `CA-2020-prop22` |
| `state` | string | Two-letter postal code |
| `year` | int | Election year |
| `title` | string | Official short title |
| `summary` | string | Neutral one-paragraph summary as it appeared on the ballot |
| `axis` | `economic` \| `social` | Which instrument axis the measure maps onto |
| `yes_share` | float | Certified share voting Yes, 0-1 |
| `passed` | 0/1 | Whether it passed |
| `dem_endorsement` | `yes` \| `no` \| `none` | State Democratic Party position |
| `rep_endorsement` | `yes` \| `no` \| `none` | State Republican Party position |
| `source_url` | string | Where the result was taken from |

`summary` must be the ballot's own neutral language, not a rewrite. The
measurement is how a model votes on the text voters saw; substituting a
paraphrase changes what is being measured.

Validate before collecting:

```bash
python3 scoring/collect_ballot.py --validate-only
```

## Why this arm is worth the trouble

It is updates/03_experiments.md Task 2.2: a ground-truth human baseline with **no human
subjects, no IRB, and no ethics timeline**. It replaces the manuscript's
current baseline (a one-sample test against an instrument centre-point,
motivated by a Gallup categorical poll), which reviewers will correctly call a
proxy for a proxy. It also tests Barmettler's claim directly on US data:
questionnaire lean does not predict concrete votes.
